# 交付清单

## 源码

- `app/`：完整页面、交互、服务端页面和 API 路由。
- `db/`：数据库访问、医院权限、账号安全与完整 Drizzle 模型。
- `drizzle/`：11 个 D1/SQLite 迁移版本及快照（0000—0010）。
- `worker/`、`build/`：当前 Sites/Cloudflare 构建入口。
- `public/`：Logo、站点图标、社交分享图等静态资源。
- `reference/stitch/`：主要页面原型 HTML、截图和设计规范参考。
- `tests/`：现有渲染、权限、数据与报告边界测试。

## 已构建页面

- `dist/client/`：浏览器端 JavaScript、CSS、图片和字体资源。
- `dist/server/`：当前 Cloudflare Worker 兼容的服务端构建产物。

注意：`dist/client/` 不是独立静态站点。登录、医院权限、数据读取、报告和文件功能均依赖服务端 API。

## 数据库与文件

- 已包含数据库结构和迁移脚本。
- 未在源码包中放入 Sites 平台数据库密码、令牌、连接串或其他密钥。
- 当前线上医院演示数据不属于 Git 源码；需要从“云端运维 → 下载医院备份”另行导出。
- Git 源码不包含 R2 中的原始文件、数据快照或报告对象；迁移时必须通过受控备份流程另行导出并核对 SHA-256。

## 验证结果

- 构建：通过。
- 自动测试：99/99 通过，包含真实 SQLite 全迁移、内存 R2 的导入—发布—更正—回滚生命周期测试和三尺寸响应式布局契约。
- 数据准备中心、医院指标基线、Published 正式供数和治理迁移已纳入本次交付版本。
