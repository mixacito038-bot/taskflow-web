# 急救设备巡检 · 护士长操作手册

> 发给：各科室护士长（科室角色账号）
> 你要做的事：**每周核查本科室这一周的巡检情况，确认无误后手写周签。**
> 手机上完成，每周一次，约 2 分钟。

---

## 一、你在流程里的位置

```
巡检员每天日签  →  你每周周签  →  设备科每月月签
        ↑                ↑                 ↑
     天天做           一周一次          一月一次
```

**上一级没做完，下一级就签不了**——这是系统硬性规定，不是提醒：

- 本周有**任何一天**巡检员没日签 → 你**签不了**周签
- 本月有**任何一周**你没周签 → 设备科**签不了**月签

所以你周签之前，先盯巡检员把日签补齐。

---

## 二、第一次使用

1. 手机扫二维码，或输入网址
2. 输入管理员发给你的**账号**和**密码**
3. 勾上 **「记住此账号，下次一键登录」**
4. 点 **「登录」**

> 建议**添加到手机桌面**：苹果 Safari 点「分享」→「添加到主屏幕」；安卓在浏览器菜单里选「添加到桌面」。

## 三、每周的操作

### 打开就是「周确认」页

登录后直接看到本科室这一周的情况：

```
周确认        急诊科
本周 · 8/3–8/9

  1/5  天已完成日签      还差 4 天
  巡检 4 台次           异常 1 台次
```

下面是一行日历（3 4 5 6 7 8 9），每天标着 **已签 / 未签**，一眼看出谁漏了。

### 情况 A：日签还没齐

页面会提示：

> **还有 4 天的日签没完成，等巡检员补签后才能周签**

这时候**周签按钮点不了**。你要做的是：

1. 看日历上哪几天是「未签」
2. 催本科室巡检员**补签**（他们首页上有提醒，点进去就能补）
3. 补齐后回来刷新，就能签了

### 情况 B：日签齐了，可以周签

1. 点 **「查看本周明细」**，看这一周巡检了什么、有哪些异常
   —— **重点看异常项**：哪台设备、什么问题，是否已经处理/报修
2. 确认无误后点周签
3. **手写签名**（手指在方框里写名字，写歪了点「清除重写」）
4. 可以填**意见**（如「异常设备已报修跟进」），也可以不填
5. 点确认提交

### ⚠ 签完不能改

周签一旦提交，**这一周的记录整体锁定**，巡检员也不能再改了。
所以签之前务必先看明细，尤其是异常项。

真签错了：找设备科作废这一周的周签，作废后可以重签。

---

## 四、异常设备怎么处理

巡检员标记的异常，你在明细里会看到具体原因（如「电池不蓄电」）。

建议流程：

1. **先处理**：能现场解决的解决，不能的报修/上报设备科
2. **再周签**：周签意见里写一句处理情况，如「除颤仪电池已更换」
3. 设备科月度核查和月报导出时，能看到全过程

> 异常不影响你周签——**发现问题并记录**本身就是巡检的价值。
> 不要为了"好看"让巡检员把异常勾成正常。

## 五、几件要知道的事

### 可以补签，不能提前签

- 上周忘了签 → 现在还能补
- 这周还没过完 → **能签**（系统按"已经过去的日期都签了"来判断）
- 下周的 → **签不了**，改手机时间也没用

### 签字人名单

签字页选的名字来自**科室签字人名单**（后台维护）。
人员变动（新来的护士、离职）要报设备科更新，否则名单里选不到人。

### 换手机

数据在服务器上，换手机登录同一账号即可，记录不丢。

## 六、常见问题

| 问题 | 怎么办 |
|---|---|
| 周签按钮点不了 | 本周还有天没日签，看日历哪天是「未签」，催巡检员补 |
| 巡检员说补不了 | 让他看首页顶部「有 N 项巡检未签字」，点进去补；超过 7 天的找设备科 |
| 明细里异常看不懂 | 巡检员填的是预设原因（如「管路老化」），拿不准直接问本人 |
| 签错了想改 | 找设备科作废该周周签，作废后重签 |
| 打不开页面 | 确认连的是**院内 WiFi**；仍不行找设备科 |
| 提示「账号已冻结」 | 密码连错多次触发保护，等几分钟自动解开，急用找管理员重置 |
| 名单里没有某个人 | 报设备科加到「签字人名单」 |
