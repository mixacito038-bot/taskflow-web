# 急救设备巡检 · 设备科操作手册

> 发给：设备科管理人员
> 你要做的事：**每月核查全院巡检情况并月签**，以及**日常盯进度、导月报、维护台账和账号**。
> 手机上月签，电脑上做管理和导出。

---

## 一、你在流程里的位置

```
巡检员每天日签  →  护士长每周周签  →  你每月月签
```

**下一级要等上一级**：本月只要有**任何一周**护士长没周签，你就签不了月签。
所以月底之前要盯各科室把周签补齐。

你还是全院唯一能看到**统计和导出**的角色。

---

## 二、手机端：每月月签

### 打开就是「月确认」页

```
月确认        8月 · 全院 1 个科室
本月 · 8月

  0/1  个科室已月度确认      等待科室周签
  巡检 4 台次              异常 1 台次
```

下面按科室列出，每个科室显示：`巡检 N 台次 · 日签 N 天 · 异常 N`、`0/1 周已签`。

顶部有 **「看上月」**，可以切到上个月补签。

### 情况 A：周签没齐

提示：**「各科室的周签尚未完成，周签齐全后才能进行月度确认」**——月签点不了。

去催对应科室的护士长补周签。

### 情况 B：可以月签

1. 点开科室，核对当月数据（巡检台次、日签天数、异常数）
2. 手写签名（手指写，写歪点「清除重写」）
3. 填意见（可选，如「当月急救设备管理良好，故障处置及时」）
4. 提交

> **月签一旦提交，当月记录整体锁定**。签之前先把异常清单过一遍。

## 三、电脑端：管理后台

浏览器打开 `http://服务器IP/admin/`，用你的账号登录。左侧菜单分三块：

### 总览

- **未签提醒** —— 打开后台第一屏。哪个科室缺日签、缺周签、缺月签，一眼扫完。
  **建议每天早上看一眼**，缺的直接点对点催。

### 巡检数据

| 菜单 | 用途 |
|---|---|
| **巡检记录** | 按科室 + 日期范围查每天的巡检，点「查看明细」看勾选详情和签名图 |
| **周签 / 月签** | 查看各科室的周签、月签卡片，含签名图和统计 |
| **异常清单** | 一段时间内全院异常汇总，可导出 xlsx |
| **统计分析** | 各科室完成率、每位签字人的工作量 |
| **月报导出** | 选科室 + 月份 → 下载 Excel 月报 |

### 月报里有什么

- 设备 × 日期的巡检矩阵（✓ 正常 / ✗ 异常 / 空 未查）
- 当月异常清单
- **日 / 周 / 月三级手写签名图**

> 这份就是给院里交的东西，打印出来即可归档。
> ⚠ **微信里点导出下载不了**（微信浏览器限制），请在电脑浏览器操作。

### 基础资料

| 菜单 | 什么时候用 |
|---|---|
| **科室管理** | 新增科室；不再参与巡检的改「停用」（别删，历史要留） |
| **设备台账** | 新增/修改设备；**批量导入**用 Excel 模板；设备报废改状态为「报废」 |
| **签字人名单** | 人员变动时维护，护士长签字时从这里选人 |

### 系统

| 菜单 | 什么时候用 |
|---|---|
| **账号管理** | 新建账号、分配角色和科室范围、重置密码、停用离职人员 |
| **历史数据导入** | 仅上线时用一次，把试用期数据迁进来 |

## 四、几件重点工作

### 1. 每天：看未签提醒

后台首页就是。缺日签的直接找巡检员，缺周签的找护士长。

### 2. 每月：月签 + 导月报

月初把上月的月签补上（手机上「看上月」），然后导出各科室月报归档。

### 3. 签错了：作废重签

管理后台里，日签在「巡检记录 → 查看明细」右下角有 **「作废该日签字」**；
周签月签在「周签 / 月签」卡片上有 **「作废」**。

- 作废需要**填写原因**，会记入审计日志
- 作废后对应人员可以重新签
- ⚠ 这是纠错通道，不是常规操作，用之前先问清楚情况

### 4. 人员变动

| 情况 | 怎么做 |
|---|---|
| 新来的巡检员 | 「账号管理」新建账号 + 「签字人名单」加名字 |
| 护士长换人 | 新建/修改账号 + 更新签字人名单（老的留着，历史签名要显示） |
| 有人离职 | 账号改「**停用**」（不要删除），停用立即踢下线，历史记录保留 |
| 忘记密码 | 「账号管理」点该账号「重置密码」，生成一次性密码当场告知本人，其**首次登录会强制改密** |

> 新建账号时设的初始密码**不会**强制修改，记得口头叮嘱本人自己改；
> 想强制的话，建完账号再点一次「重置密码」即可。

### 5. ⚠ 每周：下载备份

系统每天凌晨自动备份，但**备份和数据在同一台机器上**——机器坏了两边一起没。

**每周固定时间把 `data` 文件夹复制到另一台电脑或移动硬盘。**
这是唯一的最后防线，不能省。详见《运维手册.md》。

## 五、常见问题

| 问题 | 怎么办 |
|---|---|
| 月签点不了 | 有科室的周签没完成，去催 |
| 某科室一直不签 | 后台「未签提醒」有名单，点对点催；长期不改上报护理部 |
| 导出没反应 | 数据量大时要等十几秒，别连点；在微信里打不开，改用电脑浏览器 |
| 设备清单不对 | 「设备台账」改；批量改用 Excel 重新导入（同编码自动更新，不会重复） |
| 巡检员说看不到某台设备 | 检查该设备状态是不是「停用/报废」，或科室归属填错了 |
| 系统打不开 | 看服务器电脑是否开着、是否睡眠；详见《运维手册.md》第 8 节应急预案 |
| 服务器坏了当天怎么办 | **先记纸上，恢复后补录补签**，周签月签照常结算 |
