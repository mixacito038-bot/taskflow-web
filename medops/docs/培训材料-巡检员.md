# 急救设备巡检 · 巡检员操作手册

> 发给：各科室负责每日巡检的护士 / 技师
> 你要做的事：**每天巡检一遍本科室急救设备，勾选后手写签字。**
> 全程在手机上完成，约 2 分钟。

---

## 一、第一次使用

1. 用手机扫科室墙上的二维码（或在浏览器输入护士长给的网址）
2. 输入**账号**和**密码**（管理员发给你的）
3. 勾上 **「记住此账号，下次一键登录」**，以后打开就不用再输密码
4. 点 **「登录」**

> 建议把页面 **添加到手机桌面**，以后像 App 一样点开就用：
> 苹果 Safari 点底部「分享」→「添加到主屏幕」；安卓浏览器菜单里选「添加到桌面」。

---

## 二、每天的操作（4 步，约 2 分钟）

### 第 1 步：打开，点「开始巡检」

登录后是 **「今日任务」** 页，能看到：

- 今日 · 8月7日 周五 —— 今天的日期
- **0/4 台设备已巡检** —— 还没开始
- 一个绿色大按钮 **「开始巡检 · 急诊科」** ← 点它

> 如果你负责多个科室，会分别列出，一个个来。

### 第 2 步：逐台核对设备

进来后设备按**品类**分组（除颤仪、呼吸机、监护仪、抢救车……），
每组显示 `0/1 台`。

**全部正常时**（最常见）：
直接点底部 **「全部正常」**，一次勾完，出现 `4/4 台已巡检 全部完成，可以签字了`。

**有异常时**：
1. 点开那个品类（如「除颤仪」）
2. 能看到设备编码、型号、存放位置
3. 点设备右边的 **「异常」**
4. 弹出常见原因，直接点选：
   **外观破损 / 无法开机 / 报警异常 / 按键失灵 / 管路老化 / 电池不蓄电**
5. 点 **「确定」** → 显示「已标记异常」
6. 点 **「保存返回」** 回到清单
7. 其余正常的设备，再点 **「全部正常」** 勾完

> 标了异常的品类会显示红色 **「有异常」**。
> 你填的异常原因，**护士长周确认时会看到**，所以要写清楚。

### 第 3 步：点「日签」签字

底部点 **「日签」**，进入签字页，上面先给你看一遍统计：

```
应巡检 4 台    已巡检 4 台    正常 3 台    异常 1 台
```

然后：

1. **确认人** —— 点一下选自己的名字（名单由科室维护）
2. **手写签名** —— 用手指在方框里写名字；写歪了点 **「清除重写」**
3. **意见** —— 可以不填
4. 点 **「确认签字」**

### 第 4 步：确认签好了

页面变成 **「已日签　李强 · 2026-08-07 10:48」**，还能点「查看签名」看一眼。

**这就完成了，可以关掉了。**

## 三、几件要知道的事

### ⚠ 签完不能改

签字页上写着「**签字即锁定，提交后本日记录不可再修改**」。
所以**点确认签字前，先看一眼统计数字对不对**。

真签错了：找系统管理员（设备科）作废这一天的签字，作废后你可以重签。

### ⏰ 首页的「有效期提醒」

首页上如果出现一张 **「有效期提醒」** 卡片，说明本科室有东西快过期或已经过期了，
常见的是**除颤电极片**和**急救药品**：

| 卡片上的标记 | 含义 | 你要做的 |
|---|---|---|
| 红色 **已过期 X 天** | 已经过期，**这台设备现在不能指望** | **当天**换掉过期件，并告诉护士长 |
| 黄色 **还剩 X 天** / **今天到期** | 快到期了 | 提前准备替换件，别拖到过期 |

> 这是整套系统里唯一能防住"抢救时拿出来才发现电极片过期"的一道关，
> 看到红色不要跳过。换了新的以后，请设备科在后台把新的到期日更新上去。

没有快到期的东西时，这张卡片**不会出现**——首页干干净净就是正常的。

### 忘记巡检了怎么办 —— 可以补签

首页顶部会提醒：**「有 7 项巡检未签字」**，下面列出是哪几天。
点其中一天，就能补录那天的巡检并签字，**最近 7 天都能补**。

> 系统只允许补**过去**的日期，**不能提前签明天的**，改手机时间也没用。

### 每天什么时候做

科室自己定，建议**固定时间**（如交接班后）。
系统每天早上会提醒你昨天及最近 7 天没签的。

### 换手机、换浏览器

数据都在服务器上，换设备登录同一账号就行，记录不会丢。

## 四、常见问题

| 问题 | 怎么办 |
|---|---|
| 打不开页面 | ① 确认手机连的是**院内 WiFi**（不是 4G/5G）；② 二维码是不是贴错了；③ 都不行找设备科 |
| 提示账号或密码错误 | 连续错 5 次账号会被锁几分钟，等一会儿再试；确实忘了找管理员重置 |
| 提示「账号已冻结」 | 密码连错太多次触发保护，等提示的时间过后自动解开，急用找管理员重置密码 |
| 签名写不上去 | 用**手指**直接在方框里划，别用指甲；换个姿势或点「清除重写」再试 |
| 「日签」按钮点不了 | 还有设备没勾选，看底部提示「还有 N 台未勾选」 |
| 设备清单里少了设备 / 多了设备 | 台账要在后台改，报给设备科 |
| 有台设备停用了还在清单里 | 同上，让设备科把状态改成「停用」，就不出现在巡检清单了 |

---

**遇到问题找谁**：本科室护士长 → 设备科
