# 本地试跑指南 —— 在自己电脑上先把系统跑起来看看

> 目的：不买服务器、不要域名，先在你自己的 Windows/Mac 电脑上把整套系统跑起来点一点，
> 确认合不合用，再决定怎么部署。
>
> 两种方式，**先试方式一**，装不上再用方式二。

---

## 方式一：只装 Node.js（推荐，最快）

### 第 1 步：装 Node.js

打开 [https://nodejs.org/](https://nodejs.org/)，下载 **LTS 长期支持版**，一路下一步装完。

装完验证：Windows 按 `Win + R` 输入 `cmd` 回车，Mac 打开「终端」，输入：

```
node -v
```

显示 `v18.x` 或更高即可（如 `v22.14.0`）。

### 第 2 步：解压

把我发给你的压缩包解压，得到一个 `medops` 文件夹，放在好找的位置，例如：

- Windows：`D:\medops`
- Mac：`~/桌面/medops`

### 第 3 步：启动

在命令行里**进入 medops 文件夹**再运行启动器。

**Windows**（在 `cmd` 里）：

```
d:
cd \medops
node local\start.js
```

**Mac**（在「终端」里）：

```
cd ~/桌面/medops
node local/start.js
```

> 小技巧：Windows 可以在 medops 文件夹地址栏输入 `cmd` 回车，直接在该目录打开命令行。

**首次运行会联网下载依赖，约 1～3 分钟**，请耐心等。看到这样的画面就成功了：

```
==========================================================
  ✓ 系统已启动，用浏览器打开下面任意地址
==========================================================
  入口页        http://localhost:8080/
  巡检 H5       http://localhost:8080/xunjian/
  管理后台      http://localhost:8080/admin/
  资产盘点      http://localhost:8080/pandian/

  管理员账号    admin / admin123
==========================================================
```

### 第 4 步：打开看看

浏览器输入 `http://localhost:8080/`，用 `admin / admin123` 登录管理后台。

**停止**：回到命令行窗口按 `Ctrl + C`。
**再次启动**：重复第 3 步即可，数据都还在。

## 方式二：用 Docker（方式一装不上时）

适用于：`npm install` 报错、公司电脑限制装开发工具、或你想试与生产环境完全一致的跑法。

### 第 1 步：装 Docker Desktop

[https://www.docker.com/products/docker-desktop/](https://www.docker.com/products/docker-desktop/)
下载对应系统的版本装好，启动它（第一次会要求重启电脑）。

### 第 2 步：运行一键部署脚本

进入 `medops/deploy/local` 目录：

- **Windows**：右键「一键部署.bat」→ 以管理员身份运行
- **macOS / Linux**：`bash setup.sh`

脚本会自动生成密钥、构建镜像、启动服务，中途**让你输入管理员账号和密码**。
首次约 3～5 分钟。完成后按屏幕提示的地址打开（默认 `http://localhost/`）。

> 不要直接执行 `docker compose up -d`——密钥还没生成，会报「缺少 JWT_SECRET」。
> 首次必须先跑一次上面的脚本，之后才可以用 `docker compose up -d` 启停。

**停止 / 再启动**：

```
docker compose down      # 停止
docker compose up -d     # 启动
```

数据存在 `medops` 旁边的 `data` 文件夹（如 `D:\data`），停止不会丢。

> 这套 Docker 配置同时也是**局域网正式部署**用的。如果你打算把系统装到一台
> 专门的电脑上给全院用，请直接看《局域网电脑部署指南.md》，那份更完整
> （固定 IP、防火墙、开机自启、备份都讲了）。

## 试跑时建议走一遍的流程

按这个顺序点，10 分钟就能把系统全貌看完：

1. **管理后台** `http://localhost:8080/admin/` → `admin` / `admin123` 登录
2. 「科室管理」建两个科室，例如 急诊科(JZ)、重症医学科(ICU)
3. 「设备台账 → 批量导入」上传我发你的 **`2-设备表.xlsx`**（先填几行）
   —— 也可以先点「下载导入模板」看看格式
4. 「签字人名单」加一个护士长
5. 「账号管理」建三个账号：巡检员 / 护士长（科室）/ 设备科，各设一个密码
6. **巡检 H5** `http://localhost:8080/xunjian/`
   —— 用浏览器的**手机模式**看更真实：按 `F12` → 点左上角手机图标
   —— 用巡检员账号登录，勾选设备、手写签名、完成日签
7. 用护士长账号试**周签**（会发现日签没齐时签不了，这是设计如此）
8. 回管理后台看「巡检记录」「统计分析」，试试「月报导出」
9. **资产盘点** `http://localhost:8080/pandian/`
   —— 用管理员账号登录，看看云同步壳是怎么工作的

## 关于试跑数据

- 数据存在 `medops/data-local/`（方式一）或 `medops` 同级的 `data/` 文件夹（方式二）
- **想从零重来**：停掉服务，把这个文件夹删掉，再启动即可
- 试跑的数据和将来正式部署**没有关系**，随便折腾

## 常见问题

| 现象 | 处理 |
|---|---|
| `node 不是内部或外部命令` | Node.js 没装好或没重开命令行窗口。重装后**关掉命令行再重开** |
| `端口被占用 / EADDRINUSE` | 换端口启动：Windows `set PORT=3001 && set WEB_PORT=8081 && node local\start.js`；Mac `PORT=3001 WEB_PORT=8081 node local/start.js` |
| `npm install` 卡住或失败 | 先换国内镜像：`npm config set registry https://registry.npmmirror.com`，再重跑 |
| `better-sqlite3` 编译报错 | 电脑缺编译工具，改用**方式二 Docker** |
| 浏览器打开是空白页 | 确认地址结尾有斜杠，如 `http://localhost:8080/admin/` |
| 手机也想试 | 手机连**同一个 WiFi**，把 `localhost` 换成电脑的局域网 IP（Windows 用 `ipconfig` 查，Mac 用 `ifconfig` 查），如 `http://192.168.1.20:8080/xunjian/` |

## 试跑之后

试跑用的是 **HTTP、无证书、本机访问**，正式部署要选：

- **公网**（腾讯云，任何地方能用）→ 《部署手册.md》
- **内网**（院内服务器，数据不出院）→ 《内网部署方案.md》

两者软件完全相同，试跑没问题就说明代码没问题，剩下只是网络和证书的差别。
