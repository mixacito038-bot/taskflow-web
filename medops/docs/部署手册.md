# 部署手册 —— 从零把系统架到公网

> 本手册面向**没有服务器经验**的读者。每条命令都放在独立代码块里，
> 复制、粘贴到服务器终端、回车即可。全程约 1～2 小时（不含备案等待）。
>
> 部署完成后你将得到：
>
> | 地址 | 内容 |
> |---|---|
> | `https://你的域名/` | 统一入口页 |
> | `https://你的域名/xunjian/` | 急救设备巡检 H5（手机扫码用） |
> | `https://你的域名/admin/` | 巡检管理后台（护士长/设备科用） |
> | `https://你的域名/pandian/` | 资产盘点系统 |

---

## 第 1 步：购买云服务器

推荐 **腾讯云轻量应用服务器**（对新手最友好）：

- 打开 [https://cloud.tencent.com/product/lighthouse](https://cloud.tencent.com/product/lighthouse)，注册并实名认证；
- 配置选 **2 核 4GB 内存、60GB SSD、带宽 5M 以上**（本系统很轻，这个配置绰绰有余）；
- 地域选离医院近的（如上海、广州、南京均可）；
- 镜像（操作系统）选 **Debian 12** 或 **Ubuntu 24.04**（不要选 Windows，不要选"宝塔"之类的应用镜像）；
- 买 1 年更划算，记下服务器的**公网 IP**。

> **重要：关于备案。** 域名解析到中国大陆的服务器，必须完成 ICP 备案（免费，
> 在腾讯云控制台搜"备案"按引导操作，通常 1～2 周），否则 80/443 端口会被拦截、网站打不开。
> 不想等备案，可把服务器地域选成**香港**（免备案，延迟稍高，其余步骤完全相同）。

## 第 2 步：准备域名并解析

- 没有域名的话，在腾讯云"域名注册"买一个（几十元/年），建议简短好记，如 `yy-sbgl.com`；
- 到 [腾讯云控制台 → DNS 解析 DNSPod](https://console.cloud.tencent.com/cns) 找到你的域名，添加一条解析记录：

| 项 | 填写 |
|---|---|
| 记录类型 | `A` |
| 主机记录 | `jx`（即用 `jx.你的域名` 访问；填 `@` 则直接用主域名） |
| 记录值 | 服务器的公网 IP |
| TTL | 默认 |

- 解析生效一般几分钟。在自己电脑的命令行里验证（Windows 按 `Win+R` 输入 `cmd` 回车）：

```
ping jx.你的域名
```

返回的 IP 是服务器公网 IP 即为生效。**下文所有 `jx.example.com` 都请替换成你的真实域名。**

## 第 3 步：防火墙（安全组）只开 3 个端口

腾讯云轻量服务器控制台 → 你的服务器 → **防火墙** 页签，规则只保留这三条，其余全部删除：

| 端口 | 用途 |
|---|---|
| 22 | SSH 远程登录 |
| 80 | HTTP（自动跳转到 HTTPS + 证书验证） |
| 443 | HTTPS |

## 第 4 步：SSH 登录服务器

最简单：轻量服务器控制台点 **「登录」** 按钮，用网页终端（OrcaTerm），免装任何软件。

或者用自己电脑的终端（Windows 10+ 的 PowerShell 自带 ssh）：

```
ssh root@服务器公网IP
```

首次连接提示指纹确认输 `yes`；密码在控制台"重置密码"设置。登录成功后看到 `root@xxx:~#` 提示符。

> 下文命令均以 root 身份执行。若你用的是普通用户（如 Ubuntu 默认 `ubuntu`），命令前加 `sudo `。

## 第 5 步：安装 Docker

Debian 12 与 Ubuntu 通用（脚本会自动识别系统），使用清华大学镜像源，国内下载快：

```
apt-get update && apt-get install -y ca-certificates curl gnupg
```

```
install -m 0755 -d /etc/apt/keyrings
```

```
. /etc/os-release && curl -fsSL https://mirrors.tuna.tsinghua.edu.cn/docker-ce/linux/$ID/gpg | gpg --dearmor -o /etc/apt/keyrings/docker.gpg && chmod a+r /etc/apt/keyrings/docker.gpg
```

```
. /etc/os-release && echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://mirrors.tuna.tsinghua.edu.cn/docker-ce/linux/$ID $VERSION_CODENAME stable" > /etc/apt/sources.list.d/docker.list
```

```
apt-get update && apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

配置国内镜像加速（拉取 nginx/certbot 等基础镜像用；腾讯云内网镜像最快）：

```
mkdir -p /etc/docker && cat > /etc/docker/daemon.json <<'EOF'
{ "registry-mirrors": ["https://mirror.ccs.tencentyun.com", "https://docker.m.daocloud.io"] }
EOF
```

```
systemctl restart docker && systemctl enable docker
```

验证安装成功（应输出版本号）：

```
docker --version && docker compose version
```

## 第 6 步：上传代码到服务器

目标：把 `medops` 整个文件夹放到服务器的 `/opt/medops`。数据会自动存在旁边的
`/opt/data`（升级替换代码不影响数据）。三种方式任选其一：

**方式 A：git 克隆（代码在 git 仓库时最方便，日后升级只需 `git pull`）**

```
apt-get install -y git
```

```
git clone 你的仓库地址 /opt/app
```

```
ln -s /opt/app/medops /opt/medops
```

> 注意：用软链接时数据目录位于 `/opt/app/data`（脚本按相对位置创建）。下文出现
> `/opt/data` 的地方请对应换成 `/opt/app/data`。

**方式 B：scp 上传（在自己电脑的终端执行，Windows PowerShell 自带 scp）**

```
scp -r 本机medops文件夹路径 root@服务器公网IP:/opt/medops
```

例如 Windows：`scp -r D:\medops root@1.2.3.4:/opt/medops`

**方式 C：宝塔面板**（如果你已习惯宝塔）：安装宝塔后用其"文件"功能把 medops
压缩包上传到 `/opt` 并解压为 `/opt/medops`。注意宝塔自带的 nginx 会占用 80/443，
须在宝塔里停用它，否则本系统的 web 容器起不来。

上传后检查目录结构（应能看到 admin、ams、deploy、docs、h5、server 等子目录）：

```
ls /opt/medops
```

## 第 7 步：一键初始化

```
cd /opt/medops/deploy && bash scripts/first-run.sh
```

脚本会依次自动完成（每步有中文提示，出错即停）：

1. 生成 `.env`（自动产生强随机 JWT_SECRET），询问你的**域名**；
2. 把域名写入 nginx 配置（把 `YOUR_DOMAIN` 占位符 sed 替换掉）；
3. 创建数据目录 `/opt/data`；
4. 构建并启动后端（首次构建约 3～5 分钟）；
5. 询问并创建**管理员账号密码**（记好，登录后台用）；
6. 向 Let's Encrypt 申请免费 HTTPS 证书（要求域名解析已生效、80 端口已放行）；
7. 启动 nginx 和证书自动续期服务。

看到"部署完成"即成功。若中途失败，按提示排查后**重跑同一条命令**即可（脚本可安全重复执行）。

## 第 8 步：验证清单

在服务器上逐条执行，并对照预期结果：

```
curl -s https://jx.example.com/api/health
```

预期输出 `{"ok":true}`。

```
curl -sI http://jx.example.com/ | head -3
```

预期第一行含 `301`（HTTP 自动跳 HTTPS）。

```
docker compose -f /opt/medops/deploy/docker-compose.yml ps
```

预期 `api`（healthy）、`web`、`certbot` 三个容器都是 `Up`。

然后用**自己电脑和手机的浏览器**逐项打开：

| 检查项 | 预期 |
|---|---|
| `https://jx.example.com/` | 墨绿色统一入口页，两张大卡片 |
| 地址栏小锁图标 | 点开显示证书有效（Let's Encrypt） |
| `https://jx.example.com/xunjian/` | 巡检 H5 登录页；用管理员账号能登录 |
| `https://jx.example.com/admin/` | 管理后台登录页；管理员登录后能看到左侧菜单 |
| 后台任意页面按 F5 刷新 | 不报 404（SPA 回退正常） |
| `https://jx.example.com/pandian/` | 资产盘点登录页 |
| 手机微信里打开 `/xunjian/` | 正常显示、可登录 |

全部通过后，按 **《数据初始化.md》** 建科室、导设备、开账号。

## 第 9 步：生成二维码贴到科室

1. 打开草料二维码 [https://cli.im](https://cli.im)，选"网址"，粘贴 `https://jx.example.com/xunjian/`，生成并下载二维码图片；
2. 用 Word 排版打印：二维码 + 一行说明文字"急救设备巡检 · 微信扫码进入"，建议塑封；
3. 贴在每个科室的**急救车/除颤仪旁**或治疗室墙面；
4. 培训时让巡检员扫码后用浏览器菜单"添加到主屏幕"，以后点桌面图标直达。

## 附：常用命令速查

以下命令均先进入部署目录：

```
cd /opt/medops/deploy
```

| 操作 | 命令 |
|---|---|
| 查看服务状态 | `docker compose ps` |
| 看后端日志 | `docker compose logs -f --tail=100 api` |
| 看 nginx 日志 | `docker compose logs -f --tail=100 web` |
| 重启后端 | `docker compose restart api` |
| 全部停止 | `docker compose down`（数据不丢，都在 /opt/data） |
| 全部启动 | `docker compose up -d` |

日常备份、恢复演练、升级与故障处理见 **《运维手册.md》**。
