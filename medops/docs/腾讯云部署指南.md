# 腾讯云部署指南（Docker · 端口 8912）

> 读者：设备科负责人。**不需要会 Linux**，照着敲命令即可。
> 全程约 40 分钟，其中 5～15 分钟是机器自己在编译，你只需要等。
>
> 最终效果：全院用一个地址访问，手机扫码填巡检、电脑开后台管数据，数据都在服务器上，
> 换手机换电脑都不丢。

---

## 0. 先看这一页：整体是怎么回事

一台腾讯云服务器上跑两个「容器」：

| 容器 | 干什么 | 对外 |
|---|---|---|
| **api** | 后端：账号、签字、统计、导出 | **不对外**，只允许 nginx 内部访问 |
| **web** | nginx：发网页 + 把 `/api/` 转给后端 | 对外开 **8912** 一个端口 |

一个端口后面挂四个入口：

```
http://服务器IP:8912/            统一入口页
http://服务器IP:8912/xunjian/    巡检 H5   ← 手机端，做成二维码贴墙上
http://服务器IP:8912/admin/      管理后台  ← 设备科在电脑上用
http://服务器IP:8912/pandian/    资产盘点
```

数据全部落在服务器的 `/opt/medops-data` 目录（数据库、签名图、附件、每日自动备份）。
**这个目录就是你的全部家当**，备份就是把它拷走。代码可以随便重传覆盖，不影响它。

> ### ⚠ 关于 HTTPS，先说清楚
>
> 只开 8912 一个端口时是 **http**，登录密码在网络上是明文传输的。
>
> - **医院内网使用**（服务器在院内、只有院内网络能连）：可以接受，很多院内系统都这样。
> - **公网能访问**：建议尽快上 HTTPS。你已经有备案域名，办法见本文第 9 节，
>   用腾讯云免费证书，**不需要额外开 80 端口**，改完地址变成 `https://域名:8912/`。
>
> 我把 HTTPS 做成了一条命令，等系统跑起来、大家用顺了再补也来得及。

## 1. 买服务器（已有就跳过）

腾讯云控制台 → **轻量应用服务器** 或 **云服务器 CVM**。

| 项 | 选什么 | 说明 |
|---|---|---|
| 地域 | 离医院近的（上海就选上海） | 影响访问速度 |
| 镜像 | **Ubuntu 22.04**（推荐）或 **TencentOS Server 3** | 脚本对 apt / yum / dnf 三种包管理都做了适配 |
| 配置 | **2 核 4G** 起 | 全院几十个账号、每天几百条记录，2C4G 绰绰有余 |
| 系统盘 | 50G 起 | 签名图占地方，够用好几年 |

记下三样东西：**公网 IP**、**root 密码**（或密钥）、**登录端口**（默认 22）。

---

## 2. ⭐ 安全组放行 8912（最容易忘，忘了就"打不开"）

腾讯云控制台 → 找到你的服务器 → **防火墙 / 安全组** → **添加规则**：

| 字段 | 填什么 |
|---|---|
| 类型 | 自定义 |
| 来源 | `0.0.0.0/0`（公网可访问）；只在院内用就填医院出口 IP 段，更安全 |
| 协议端口 | **TCP:8912** |
| 策略 | 允许 |

> 后面第 7 步如果出现「服务器上自检全过，但浏览器打不开」，**99% 就是这一步没做**。

---

## 3. 连上服务器

**Mac 用自带的「终端」**（聚焦搜索里输 Terminal 回车），执行：

```bash
ssh root@你的服务器公网IP
```

第一次会问 `Are you sure...`，输 `yes` 回车，再输密码（**输密码时屏幕不动是正常的**，输完直接回车）。

看到 `root@VM-x-x:~#` 就是连上了。

---

## 4. 把源码包传上去

**在你自己的 Mac 上另开一个终端窗口**（不要在刚连上服务器的那个里敲），执行：

```bash
# 把下载的 zip 传到服务器（假设文件在"下载"文件夹）
scp ~/Downloads/医院急救设备巡检系统-完整源码.zip root@你的服务器公网IP:/root/
```

传完回到**服务器那个窗口**，解压：

```bash
cd /root
# 装解压工具（三条挑能跑通的一条，报错的忽略）
command -v unzip >/dev/null || yum install -y unzip || dnf install -y unzip || apt-get install -y unzip

# ⭐ 先把中文名改成英文名，再解压
mv 医院*.zip medops.zip
unzip -o medops.zip -d /opt/
ls /opt/medops        # 应该能看到 server admin h5 deploy docs 等目录
```

> ### ⚠ 为什么一定要先改名
>
> 如果你不小心下载了两次，浏览器会把文件命名成
> `医院急救设备巡检系统-完整源码 (1).zip` —— **多了一个空格和一对括号**。
> 括号在 Linux 命令行里有特殊含义，直接 `unzip` 那个名字会报：
>
> ```
> -bash: syntax error near unexpected token `('
> ```
>
> 先 `mv` 成 `medops.zip`，后面就再也不用跟中文文件名和括号较劲了。
> （`医院*.zip` 里的 `*` 是通配符，会自动匹配到你那个文件，不用手打全名。）

代码就在 `/opt/medops` 了。

---

## 4.5 如果这台机器上还跑着别的业务

服务器如果不是全新的（比如上面已经有永洪 BI、宝塔之类），先花一分钟确认两件事：

```bash
docker --version && docker compose version    # 已经装过 Docker 就会打印版本号
ss -lntp | grep -E ':8912' || echo "8912 没被占用"
```

| 情况 | 怎么办 |
|---|---|
| Docker 已装 | 下一步的安装脚本会自动跳过安装，只做必要检查 |
| **8912 已被占用** | 换个端口：`.env` 里把 `WEB_PORT` 改成 8913，安全组也放行新端口 |
| 8912 空闲 | 直接往下走 |

> **不用担心影响现有业务**：巡检系统跑在自己的 Docker 容器里，
> 只占 8912 一个端口，数据单独放在 `/opt/medops-data`，
> 不碰现有服务的文件、端口和数据库。
>
> 唯一一处会影响到别人的操作是「配置 Docker 镜像加速」——那需要重启 Docker 守护进程，
> **会让这台机器上所有容器一起重启**。所以安装脚本做了保护：
> 只有在检测到确实拉不动镜像时才会提出，并且**会先列出当前在跑的容器、让你确认**，
> 你直接回车就是跳过。

## 5. 装 Docker

```bash
cd /opt/medops/deploy/tencent
sudo bash install-docker.sh
```

这个脚本会：装 Docker（已装则跳过）→ **配置国内镜像加速**。

> 第二步很关键。腾讯云的机器直连 Docker Hub 经常超时，不配加速的话下一步会卡在
> 「pulling」半天不动。脚本用的 `mirror.ccs.tencentyun.com` 是腾讯云内网源，又快又稳。

---

## 6. 一键部署

```bash
cd /opt/medops/deploy/tencent
bash deploy.sh
```

脚本会依次做 8 件事，全程有中文提示：

1. 生成配置（含随机密钥，自动写进 `.env`）
2. 建数据目录 `/opt/medops-data`
3. 放行服务器本机防火墙（顺便提醒你安全组那一步）
4. 探测 npm 源通不通，自动挑一个能用的（国内镜像优先，不通就换官方源）
5. **构建并启动后端** ← 这里要等，屏幕上会一直滚日志，**别关窗口**
6. **让你创建管理员账号**（账号名建议 `admin`，密码至少 6 位，输两遍）
7. 启动网站
8. 自检五个地址 + 检查端口跳转

跑完会打印四个访问地址。**这个脚本可以反复执行**，配置、管理员、数据都不会被覆盖。

> ### 第 5 步要等多久？
>
> 正常 **5～8 分钟**（`better-sqlite3` 要现场编译）。看到
> `==== 第 1 次安装依赖 ====` 之后长时间没动静是**正常的**，不是卡死。
>
> npm 偶尔会抽风（打印 `Exit handler never called!`），系统会**自动清理重装**，
> 最多试 3 轮，最坏情况约 15 分钟。屏幕上会出现
> `第 1 次装完不完整…清理后重试`，看到这句不用管，等它自己走完。
>
> 三轮都不成会明确报错并停下（不会产出一个"装了一半"的坏系统），
> 这时按提示检查服务器能否访问 npm 源。

## 7. 验收

在**你自己的电脑浏览器**里逐个打开：

- [ ] `http://IP:8912/` → 看到入口页
- [ ] `http://IP:8912/admin/` → 用刚建的管理员登录，进得去
- [ ] `http://IP:8912/api/health` → 显示 `{"ok":true}`
- [ ] **手机连 4G**（不是院内 WiFi）打开 `http://IP:8912/xunjian/` → 登录页正常
- [ ] 用**微信**扫二维码打开同一个地址 → 能显示能登录

| 症状 | 原因 |
|---|---|
| `syntax error near unexpected token '('` | 文件名里有括号没加引号。按第 4 步先 `mv` 改成英文名 |
| `apt-get: command not found` | 正常现象，你的系统用 yum/dnf，后面的命令会接上 |
| `端口 8912 已被别的程序占用` | 这台机器上有别的服务在用这个端口，换一个：`bash manage.sh 改端口 8913` |
| 服务器上自检全过，浏览器一直转圈打不开 | **安全组没放行 8912**（回第 2 步） |
| 交接班时有人提示「请求过于频繁」 | 全院共用一个出口 IP，限流阈值偏紧。改 `.env` 里的 `RL_LOGIN` / `RL_GLOBAL` 调大，再 `bash manage.sh 升级` |
| 全部打不开，服务器上自检也不过 | `bash manage.sh 状态` 看容器；`bash manage.sh 日志` 看报错 |
| 能打开但点什么都报错 | 后端没起来，`bash manage.sh 日志` |

## 7.5 打印巡检二维码贴墙上

部署完成后，直接在浏览器打开：

```
http://服务器IP:8912/qrcode.html
```

IP 和端口会**自动填好**，填一下科室名（如「急诊科抢救室」）→ 生成 → `Ctrl/⌘ + P` 直接打印。

每个科室印一张贴在抢救室墙上，护士拿手机微信扫一扫就能进巡检页面。
建议在二维码旁边手写上本科室巡检员的账号名，新同事不用问人。

> 换了服务器 IP 或端口后，二维码要重新生成打印（里面写死了地址）。

cd /opt/medops/deploy/tencent && bash manage.sh 帮助

常用：

## 9. 绑域名 + 上 HTTPS

做完这一节，地址从 `http://49.234.179.153:8912/` 变成 `https://你的域名/`——
干净、加密、地址栏有绿锁。

### 9.0 先分清两件事

| 你想要什么 | 需要做什么 |
|---|---|
| 域名能访问（地址带 `:8912`） | **只加 DNS 解析**，服务器什么都不用改 |
| 地址栏有绿锁（加密） | 装证书，**8912 上也能装** |
| 地址里**不带端口号** | 才需要改成 443 |

也就是说 **443 唯一的作用是让地址不带端口号**。不追求这个的话，
装完证书停在 `https://域名:8912/` 完全没问题。

> **一个值得认真考虑 443 的现实理由**：有些医院内网会限制非标准端口出站。
> 先拿一台手机**连院内 WiFi**（不是 4G）打开 `http://服务器IP:8912/`——
> 打不开就说明院内网络挡了非标端口，那就该上 443（443 几乎不会被挡）。

### 9.1 加 DNS 解析

在域名服务商（腾讯云 DNSPod 等）加一条记录：

| 字段 | 填什么 |
|---|---|
| 记录类型 | **A** |
| 主机记录 | `xunjian`（想用主域名就填 `@`） |
| 记录值 | 你的服务器公网 IP |
| TTL | 600 |

等几分钟，在自己电脑上验证：`ping xunjian.你的域名.com`，返回你的服务器 IP 即生效。

> **一个子域名就够。** 四个入口是按路径分的（`/xunjian/`、`/admin/`、`/pandian/`），
> 不需要买或配多个域名。

> ⚠ **域名必须已完成 ICP 备案。** 解析到大陆服务器后，未备案域名访问 80/443
> 会被拦截——这是硬性规定。备案期间可以继续用 IP:8912，不影响推进。

### 9.2 申请免费证书

腾讯云控制台 → **SSL 证书** → 申请**免费证书**（域名型 DV）→ 按提示做 DNS 验证。

签发后下载 **Nginx 版**，解压得到两个文件。⚠ **`.crt` 要用带 `_bundle` 的那个**
（含完整证书链，否则部分安卓手机会报证书不受信任）。

### 9.3 上传证书并启用

在自己 Mac 上：

```bash
ssh root@服务器IP "mkdir -p /root/cert"
scp ~/Downloads/你的域名_nginx/*_bundle.crt ~/Downloads/你的域名_nginx/*.key root@服务器IP:/root/cert/
```

回到服务器：

```bash
cd /opt/medops/deploy/tencent
ls /root/cert/                                    # 看清楚两个文件的实际名字
bash enable-https.sh /root/cert/xxx_bundle.crt /root/cert/xxx.key
```

脚本会问你**要不要顺便配 http→https 自动跳转**（80 端口空闲时才问）：

- 输 `yes`：用户在浏览器直接敲域名也能进，会自动跳到 https。**需要安全组也放行 80**
- 直接回车跳过：用户必须完整输入 `https://` 或扫二维码才能进

证书有问题时脚本会自己校验 nginx 配置，**不通过就自动回滚到 HTTP**，不会把站点弄挂。

### 9.4 改成 443

```bash
bash manage.sh 改端口 443
```

脚本会**先查 443 有没有被别的程序占用**——被占的话什么都不改，站点继续在原端口正常跑。

然后到腾讯云安全组：**放行 443**（选了跳转就再放行 80），8912 可以删掉。

### 9.5 验收

- [ ] `https://你的域名/` 能打开，地址栏有绿锁
- [ ] `https://你的域名/xunjian/` 手机能打开、能登录
- [ ] 微信扫码能打开
- [ ] 选了跳转的话：浏览器敲 `你的域名`（不写 https://）能自动跳过去
- [ ] `bash manage.sh 状态` 能看到证书剩余天数

### 9.6 ⚠ 换了地址，二维码要重印

二维码里写死了地址。切到域名后，打开 `https://你的域名/qrcode.html`
重新生成并打印，把各科室墙上的旧二维码换掉。

### 9.7 证书 90 天到期

腾讯云免费证书 **90 天有效**。到期前重新申请、下载，再跑一次
`bash enable-https.sh 新证书.crt 新证书.key` 即可（不用再改端口）。

`bash manage.sh 状态` 会显示剩余天数，**剩 15 天以内会提示**。
建议现在就在手机日历上设一个提前 10 天的提醒。

想改回 HTTP：`bash enable-https.sh --off`，再 `bash manage.sh 改端口 8912`。

## 10. 换服务器 / 重装怎么办

数据只在 `/opt/medops-data`。搬家三步：

```bash
# 老机器上
cd /opt/medops/deploy/tencent && bash manage.sh 备份 /root/final.tar.gz
# 下载到本地，再上传到新机器，然后在新机器上
# （新机器先走完第 4～6 步，把系统跑起来）
cd /opt/medops/deploy/tencent && bash manage.sh 恢复 /root/final.tar.gz
```
