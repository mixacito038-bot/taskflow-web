# 腾讯云部署指南（Docker · 端口 8912）

> 读者：设备科负责人。**不需要会 Linux**，照着敲命令即可。
> 全程约 40 分钟，其中 5～15 分钟是机器自己在编译，你只需要等。
>
> 最终效果：全院用一个地址访问，手机扫码填巡检、电脑开后台管数据，数据都在服务器上，
> 换手机换电脑都不丢。

---

## 0. 先看这一页：整体是怎么回事

一台腾讯云服务器上跑两个「容器」：

| 容器 | 干什么 | 对外 |
|---|---|---|
| **api** | 后端：账号、签字、统计、导出 | **不对外**，只允许 nginx 内部访问 |
| **web** | nginx：发网页 + 把 `/api/` 转给后端 | 对外开 **8912** 一个端口 |

一个端口后面挂四个入口：

```
http://服务器IP:8912/            统一入口页
http://服务器IP:8912/xunjian/    巡检 H5   ← 手机端，做成二维码贴墙上
http://服务器IP:8912/admin/      管理后台  ← 设备科在电脑上用
http://服务器IP:8912/pandian/    资产盘点
```

数据全部落在服务器的 `/opt/medops-data` 目录（数据库、签名图、附件、每日自动备份）。
**这个目录就是你的全部家当**，备份就是把它拷走。代码可以随便重传覆盖，不影响它。

> ### ⚠ 关于 HTTPS，先说清楚
>
> 只开 8912 一个端口时是 **http**，登录密码在网络上是明文传输的。
>
> - **医院内网使用**（服务器在院内、只有院内网络能连）：可以接受，很多院内系统都这样。
> - **公网能访问**：建议尽快上 HTTPS。你已经有备案域名，办法见本文第 9 节，
>   用腾讯云免费证书，**不需要额外开 80 端口**，改完地址变成 `https://域名:8912/`。
>
> 我把 HTTPS 做成了一条命令，等系统跑起来、大家用顺了再补也来得及。

## 1. 买服务器（已有就跳过）

腾讯云控制台 → **轻量应用服务器** 或 **云服务器 CVM**。

| 项 | 选什么 | 说明 |
|---|---|---|
| 地域 | 离医院近的（上海就选上海） | 影响访问速度 |
| 镜像 | **Ubuntu 22.04**（推荐）或 **TencentOS Server 3** | 脚本对 apt / yum / dnf 三种包管理都做了适配 |
| 配置 | **2 核 4G** 起 | 全院几十个账号、每天几百条记录，2C4G 绰绰有余 |
| 系统盘 | 50G 起 | 签名图占地方，够用好几年 |

记下三样东西：**公网 IP**、**root 密码**（或密钥）、**登录端口**（默认 22）。

---

## 2. ⭐ 安全组放行 8912（最容易忘，忘了就"打不开"）

腾讯云控制台 → 找到你的服务器 → **防火墙 / 安全组** → **添加规则**：

| 字段 | 填什么 |
|---|---|
| 类型 | 自定义 |
| 来源 | `0.0.0.0/0`（公网可访问）；只在院内用就填医院出口 IP 段，更安全 |
| 协议端口 | **TCP:8912** |
| 策略 | 允许 |

> 后面第 7 步如果出现「服务器上自检全过，但浏览器打不开」，**99% 就是这一步没做**。

---

## 3. 连上服务器

**Mac 用自带的「终端」**（聚焦搜索里输 Terminal 回车），执行：

```bash
ssh root@你的服务器公网IP
```

第一次会问 `Are you sure...`，输 `yes` 回车，再输密码（**输密码时屏幕不动是正常的**，输完直接回车）。

看到 `root@VM-x-x:~#` 就是连上了。

---

## 4. 把源码包传上去

**在你自己的 Mac 上另开一个终端窗口**（不要在刚连上服务器的那个里敲），执行：

```bash
# 把下载的 zip 传到服务器（假设文件在"下载"文件夹）
scp ~/Downloads/医院急救设备巡检系统-完整源码.zip root@你的服务器公网IP:/root/
```

传完回到**服务器那个窗口**，解压：

```bash
cd /root
# 装解压工具（三种系统各一条，跑哪条成功都行，报错的那条忽略即可）
apt-get update -y && apt-get install -y unzip || yum install -y unzip || dnf install -y unzip

unzip -o 医院急救设备巡检系统-完整源码.zip -d /opt/
ls /opt/medops        # 应该能看到 server admin h5 deploy docs 等目录
```

> 文件名带中文，敲到 `unzip -o 医` 时按 **Tab 键**可以自动补全，不用手打。

代码就在 `/opt/medops` 了。

---

## 5. 装 Docker

```bash
cd /opt/medops/deploy/tencent
sudo bash install-docker.sh
```

这个脚本会：装 Docker（已装则跳过）→ **配置国内镜像加速**。

> 第二步很关键。腾讯云的机器直连 Docker Hub 经常超时，不配加速的话下一步会卡在
> 「pulling」半天不动。脚本用的 `mirror.ccs.tencentyun.com` 是腾讯云内网源，又快又稳。

---

## 6. 一键部署

```bash
cd /opt/medops/deploy/tencent
bash deploy.sh
```

脚本会依次做 8 件事，全程有中文提示：

1. 生成配置（含随机密钥，自动写进 `.env`）
2. 建数据目录 `/opt/medops-data`
3. 放行服务器本机防火墙（顺便提醒你安全组那一步）
4. 探测 npm 源通不通，自动挑一个能用的（国内镜像优先，不通就换官方源）
5. **构建并启动后端** ← 这里要等，屏幕上会一直滚日志，**别关窗口**
6. **让你创建管理员账号**（账号名建议 `admin`，密码至少 6 位，输两遍）
7. 启动网站
8. 自检五个地址 + 检查端口跳转

跑完会打印四个访问地址。**这个脚本可以反复执行**，配置、管理员、数据都不会被覆盖。

> ### 第 5 步要等多久？
>
> 正常 **5～8 分钟**（`better-sqlite3` 要现场编译）。看到
> `==== 第 1 次安装依赖 ====` 之后长时间没动静是**正常的**，不是卡死。
>
> npm 偶尔会抽风（打印 `Exit handler never called!`），系统会**自动清理重装**，
> 最多试 3 轮，最坏情况约 15 分钟。屏幕上会出现
> `第 1 次装完不完整…清理后重试`，看到这句不用管，等它自己走完。
>
> 三轮都不成会明确报错并停下（不会产出一个"装了一半"的坏系统），
> 这时按提示检查服务器能否访问 npm 源。

## 7. 验收

在**你自己的电脑浏览器**里逐个打开：

- [ ] `http://IP:8912/` → 看到入口页
- [ ] `http://IP:8912/admin/` → 用刚建的管理员登录，进得去
- [ ] `http://IP:8912/api/health` → 显示 `{"ok":true}`
- [ ] **手机连 4G**（不是院内 WiFi）打开 `http://IP:8912/xunjian/` → 登录页正常
- [ ] 用**微信**扫二维码打开同一个地址 → 能显示能登录

| 症状 | 原因 |
|---|---|
| 服务器上自检全过，浏览器一直转圈打不开 | **安全组没放行 8912**（回第 2 步） |
| 交接班时有人提示「请求过于频繁」 | 全院共用一个出口 IP，限流阈值偏紧。改 `.env` 里的 `RL_LOGIN` / `RL_GLOBAL` 调大，再 `bash manage.sh 升级` |
| 全部打不开，服务器上自检也不过 | `bash manage.sh 状态` 看容器；`bash manage.sh 日志` 看报错 |
| 能打开但点什么都报错 | 后端没起来，`bash manage.sh 日志` |

## 7.5 打印巡检二维码贴墙上

部署完成后，直接在浏览器打开：

```
http://服务器IP:8912/qrcode.html
```

IP 和端口会**自动填好**，填一下科室名（如「急诊科抢救室」）→ 生成 → `Ctrl/⌘ + P` 直接打印。

每个科室印一张贴在抢救室墙上，护士拿手机微信扫一扫就能进巡检页面。
建议在二维码旁边手写上本科室巡检员的账号名，新同事不用问人。

> 换了服务器 IP 或端口后，二维码要重新生成打印（里面写死了地址）。

## 8. 日常运维（记这一条就够）

```bash
cd /opt/medops/deploy/tencent && bash manage.sh 帮助
```

常用：

| 想干什么 | 命令 |
|---|---|
| 看是不是正常 | `bash manage.sh 状态` |
| 看报错 | `bash manage.sh 日志` |
| **备份** | `bash manage.sh 备份` ← 会顺便打印把备份拉回本地的命令 |
| 忘了管理员密码 | `bash manage.sh 重置管理员` |
| 传了新代码要升级 | `bash manage.sh 升级` |
| 换端口 | `bash manage.sh 改端口 9000` |

> **每周固定做一次备份并拉回院内电脑。** 系统每天凌晨 2:30 会自动备份，
> 但备份和数据在同一台机器上——机器坏了两边一起没。详见《运维手册.md》。

## 9. 以后要上 HTTPS（可选，建议公网访问时做）

1. 腾讯云控制台 → **SSL 证书** → 申请**免费证书**（域名型 DV），按提示做 DNS 验证
2. 签发后下载 **Nginx 版**，解压得到 `.crt` 和 `.key` 两个文件
3. 在 Mac 上传到服务器：
   ```bash
   scp ~/Downloads/你的域名_nginx/*.crt ~/Downloads/你的域名_nginx/*.key root@服务器IP:/root/cert/
   ```
4. 服务器上执行：
   ```bash
   cd /opt/medops/deploy/tencent
   bash enable-https.sh /root/cert/xxx.crt /root/cert/xxx.key
   ```

地址变成 `https://你的域名:8912/`。想去掉端口号显示成 `https://你的域名/`，
就再执行 `bash manage.sh 改端口 443`，并在安全组放行 443。

想改回 HTTP：`bash enable-https.sh --off`。
证书有问题时脚本会自己校验 nginx 配置，不通过就**自动回滚到 HTTP**，不会把站点弄挂。

> 腾讯云免费证书 **90 天到期**，到期前重新申请并再跑一次 `enable-https.sh` 即可。
> 建议在手机日历上设一个提前 10 天的提醒。

## 10. 换服务器 / 重装怎么办

数据只在 `/opt/medops-data`。搬家三步：

```bash
# 老机器上
cd /opt/medops/deploy/tencent && bash manage.sh 备份 /root/final.tar.gz
# 下载到本地，再上传到新机器，然后在新机器上
# （新机器先走完第 4～6 步，把系统跑起来）
cd /opt/medops/deploy/tencent && bash manage.sh 恢复 /root/final.tar.gz
```
