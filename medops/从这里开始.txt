急救设备巡检系统 + 资产盘点云同步
====================================

想先在自己电脑上跑起来看看？
--> 打开 docs/本地试跑指南.md，照第一段做即可（装个 Node.js，运行一条命令）

最快版本（已装 Node.js 的话）：
  1. 在本文件夹打开命令行
     Windows：在上方地址栏输入 cmd 回车
     Mac：右键文件夹 →「服务」→「新建位于文件夹位置的终端窗口」
  2. 输入并回车：
       node local/start.js
  3. 浏览器打开 http://localhost:8080/
     管理员账号 admin / admin123

  停止：命令行窗口按 Ctrl + C


正式部署（推荐 Docker）
------------------------------------
--> 看 docs/局域网电脑部署指南.md

  Mac / Linux：
      cd ~/medops/deploy/local
      bash setup.sh
  Windows：
      进 deploy\local，右键「一键部署.bat」→ 以管理员身份运行

  为什么用 Docker：本地跑通的这一套，以后原样搬到云服务器即可，
  行为完全一致，不会出现「本地好好的、服务器上就不行」。

  注意：Mac 请把 medops 放在个人文件夹下（~/medops），
        放 /opt 下 Docker Desktop 默认不共享，会挂载失败。
  注意：Mac 上 .bat 是给 Windows 用的，双击没反应属正常。


备用方案：装不上 Docker 时用 Node
------------------------------------
--> 看 docs/Mac-Node部署指南.md
      cd ~/medops/deploy/nodejs && bash setup.sh

  功能完全一样，只是少了容器隔离、以后搬去服务器要重新配环境。
  两套共用同一个 data 文件夹，随时可以互换，数据不用动。


文件夹里都是什么
------------------------------------
docs/           全部说明文档（先看这里）
  局域网电脑部署指南.md 用 Docker 部署到一台电脑，全院共用 ← 主要看这份
  本地试跑指南.md      只想先快速看看效果时用
  Mac-Node部署指南.md   备用：装不上 Docker 时改用 Node
  上线前检查清单.md    正式上线前逐条打勾
  部署手册.md          部署到腾讯云（公网）
  内网部署方案.md      内网部署的网络/证书/时间同步方案
  运维手册.md          备份、恢复、故障处理
  数据初始化.md        建科室、导设备、建账号
  培训材料-巡检员.md    发给一线护士/技师（每天日签）
  培训材料-护士长.md    发给各科室护士长（每周周签）
  培训材料-设备科.md    发给设备科（每月月签 + 后台管理）
  templates/           三张数据准备 Excel 模板

local/          本地试跑启动器
server/         后端服务（接口、数据库、权限、导出）
admin/          管理后台网页（护士长、设备科用）
h5/             手机端巡检页面（扫码打开）
ams/            资产盘点系统 + 云同步壳
  original/       你的原始文件（一个字节未改）
  dist/           注入同步壳后的可部署版本
deploy/         部署配置
  local/          Docker 方案（主线，含一键部署脚本）
  nodejs/         Node 方案（备用，不依赖 Docker）


四个访问地址
------------------------------------
本机试跑（node local/start.js）用 8080 端口：
  http://localhost:8080/            入口页
  http://localhost:8080/xunjian/    巡检 H5（手机扫码）
  http://localhost:8080/admin/      管理后台
  http://localhost:8080/pandian/    资产盘点

Docker 局域网部署默认 80 端口，把 localhost:8080 换成服务器 IP 即可：
  http://192.168.1.50/xunjian/   等等

一台服务器就够，四个入口共用同一个地址，不需要分开买多个域名。
