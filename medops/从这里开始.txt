急救设备巡检系统 + 资产盘点云同步
====================================

想先在自己电脑上跑起来看看？
--> 打开 docs/本地试跑指南.md，照第一段做即可（装个 Node.js，运行一条命令）

最快版本（已装 Node.js 的话）：
  1. 在本文件夹打开命令行
     Windows：在上方地址栏输入 cmd 回车
     Mac：右键文件夹 →「服务」→「新建位于文件夹位置的终端窗口」
  2. 输入并回车：
       node local/start.js
  3. 浏览器打开 http://localhost:8080/
     管理员账号 admin / admin123

  停止：命令行窗口按 Ctrl + C


部署到腾讯云服务器（全院公网/内网访问，端口 8912）★ 当前主线
------------------------------------
--> 看 docs/腾讯云部署指南.md

  1. 腾讯云安全组放行 8912 端口（网页控制台做，最容易忘）
  2. 在自己 Mac 上传源码包：
       scp ~/Downloads/医院急救设备巡检系统-完整源码.zip root@服务器IP:/root/
  3. ssh 上服务器，解压到 /opt：
       unzip -o /root/医院急救设备巡检系统-完整源码.zip -d /opt/
  4. 装 Docker（含国内镜像加速，不配会卡在拉镜像）：
       cd /opt/medops/deploy/tencent && sudo bash install-docker.sh
  5. 一键部署（会让你设管理员账号密码）：
       bash deploy.sh

  跑完自动自检五个地址并打印访问链接。日常运维：bash manage.sh 帮助


先在自己电脑上用 Docker 试跑
------------------------------------
--> 看 docs/局域网电脑部署指南.md

  Mac / Linux：
      cd ~/medops/deploy/local
      bash setup.sh
  Windows：
      进 deploy\local，右键「一键部署.bat」→ 以管理员身份运行

  为什么用 Docker：本地跑通的这一套，以后原样搬到云服务器即可，
  行为完全一致，不会出现「本地好好的、服务器上就不行」。

  注意：Mac 请把 medops 放在个人文件夹下（~/medops），
        放 /opt 下 Docker Desktop 默认不共享，会挂载失败。
  注意：Mac 上 .bat 是给 Windows 用的，双击没反应属正常。


备用方案：装不上 Docker 时用 Node
------------------------------------
--> 看 docs/Mac-Node部署指南.md
      cd ~/medops/deploy/nodejs && bash setup.sh

  功能完全一样，只是少了容器隔离、以后搬去服务器要重新配环境。
  两套共用同一个 data 文件夹，随时可以互换，数据不用动。

四个访问地址
------------------------------------
本机试跑（node local/start.js）用 8080 端口：
  http://localhost:8080/            入口页
  http://localhost:8080/xunjian/    巡检 H5（手机扫码）
  http://localhost:8080/admin/      管理后台
  http://localhost:8080/pandian/    资产盘点

腾讯云部署用 8912 端口：
  http://服务器公网IP:8912/            入口页
  http://服务器公网IP:8912/xunjian/    巡检 H5（做成二维码贴墙上）
  http://服务器公网IP:8912/admin/      管理后台
  http://服务器公网IP:8912/pandian/    资产盘点

一台服务器、一个端口就够，四个入口共用同一个地址，不需要买多个域名。
以后想上 HTTPS：deploy/tencent/enable-https.sh（腾讯云免费证书，不用额外开 80 端口）。
