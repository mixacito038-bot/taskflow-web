急救设备巡检系统 + 资产盘点云同步
====================================

想先在自己电脑上跑起来看看？
--> 打开 docs/本地试跑指南.md，照第一段做即可（装个 Node.js，运行一条命令）

最快版本（已装 Node.js 的话）：
  1. 在本文件夹打开命令行
     Windows：在上方地址栏输入 cmd 回车
     Mac：右键文件夹 →「服务」→「新建位于文件夹位置的终端窗口」
  2. 输入并回车：
       node local/start.js
  3. 浏览器打开 http://localhost:8080/
     管理员账号 admin / admin123

  停止：命令行窗口按 Ctrl + C


文件夹里都是什么
------------------------------------
docs/           全部说明文档（先看这里）
  本地试跑指南.md      在自己电脑上试跑 ← 现在看这个
  上线前检查清单.md    正式上线前逐条打勾
  部署手册.md          部署到腾讯云（公网）
  内网部署方案.md      部署到院内服务器（内网）
  运维手册.md          备份、恢复、故障处理
  数据初始化.md        建科室、导设备、建账号
  templates/           三张数据准备 Excel 模板

local/          本地试跑启动器
server/         后端服务（接口、数据库、权限、导出）
admin/          管理后台网页（护士长、设备科用）
h5/             手机端巡检页面（扫码打开）
ams/            资产盘点系统 + 云同步壳
  original/       你的原始文件（一个字节未改）
  dist/           注入同步壳后的可部署版本
deploy/         部署配置（Docker、nginx）
  local/          本地/内网纯 HTTP 配置


四个访问地址（部署后同理，把 localhost:8080 换成域名）
------------------------------------
http://localhost:8080/            入口页
http://localhost:8080/xunjian/    巡检 H5（手机扫码）
http://localhost:8080/admin/      管理后台
http://localhost:8080/pandian/    资产盘点

一台服务器、一个域名就够，不需要分开买多个域名。
