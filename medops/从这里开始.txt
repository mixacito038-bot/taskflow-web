急救设备巡检系统 + 资产盘点云同步
====================================

想先在自己电脑上跑起来看看？
--> 打开 docs/本地试跑指南.md，照第一段做即可（装个 Node.js，运行一条命令）

最快版本（已装 Node.js 的话）：
  1. 在本文件夹打开命令行
     Windows：在上方地址栏输入 cmd 回车
     Mac：右键文件夹 →「服务」→「新建位于文件夹位置的终端窗口」
  2. 输入并回车：
       node local/start.js
  3. 浏览器打开 http://localhost:8080/
     管理员账号 admin / admin123

  停止：命令行窗口按 Ctrl + C


想正式部署到一台电脑上给全院用？两条路，功能完全一样，选一条即可
------------------------------------
【A】只装 Node.js（轻、简单，Mac 推荐）
  --> 看 docs/Mac-Node部署指南.md
      cd ~/medops/deploy/nodejs
      bash setup.sh

【B】用 Docker（多一层隔离，Windows 推荐）
  --> 看 docs/局域网电脑部署指南.md
      Windows：进 deploy\local，右键「一键部署.bat」→ 以管理员身份运行
      Mac / Linux：cd ~/medops/deploy/local && bash setup.sh

两套用的是同一个 data 文件夹，以后想换过去，停掉服务直接换，数据不用动。

注意：Mac 上 .bat 是给 Windows 用的，双击没反应属正常。
注意：Mac 请把 medops 放在个人文件夹下（~/medops）；Docker 方案放 /opt 会挂载失败。


文件夹里都是什么
------------------------------------
docs/           全部说明文档（先看这里）
  本地试跑指南.md      在自己电脑上快速试跑 ← 先看这个
  Mac-Node部署指南.md   Mac 上正式部署，只装 Node.js ← 不想装 Docker 看这份
  局域网电脑部署指南.md 用 Docker 正式部署，全院共用
  上线前检查清单.md    正式上线前逐条打勾
  部署手册.md          部署到腾讯云（公网）
  内网部署方案.md      内网部署的网络/证书/时间同步方案
  运维手册.md          备份、恢复、故障处理
  数据初始化.md        建科室、导设备、建账号
  templates/           三张数据准备 Excel 模板

local/          本地试跑启动器
server/         后端服务（接口、数据库、权限、导出）
admin/          管理后台网页（护士长、设备科用）
h5/             手机端巡检页面（扫码打开）
ams/            资产盘点系统 + 云同步壳
  original/       你的原始文件（一个字节未改）
  dist/           注入同步壳后的可部署版本
deploy/         部署配置
  nodejs/         Node 方案（不用 Docker，含开机自启与管理脚本）
  local/          Docker 方案（局域网纯 HTTP，含一键部署脚本）


四个访问地址
------------------------------------
本机试跑（node local/start.js）用 8080 端口：
  http://localhost:8080/            入口页
  http://localhost:8080/xunjian/    巡检 H5（手机扫码）
  http://localhost:8080/admin/      管理后台
  http://localhost:8080/pandian/    资产盘点

Docker 局域网部署默认 80 端口，把 localhost:8080 换成服务器 IP 即可：
  http://192.168.1.50/xunjian/   等等

一台服务器就够，四个入口共用同一个地址，不需要分开买多个域名。
