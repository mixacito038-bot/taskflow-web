# 单机试用 · 快速开始

服务器 `49.234.179.153`，端口 `8911`，不用域名、不用证书、不用 Docker。
所有东西都装在 `/opt/yonghong` 一棵树下，删这个目录就等于卸载干净。

```
/opt/yonghong/
├── src/            上传解压的源码（含构建产物）
├── app/            实际运行的程序
├── data/           数据库 + 上传文件 + 报告   ← 备份就备份这个
└── yonghong.env    配置（管理员密码、入口口令）
```

---

## 第 1 步：本地上传（在你自己电脑上执行）

```bash
scp yonghong-platform-src-2026.08.12.tar.gz root@49.234.179.153:/root/
```

## 第 2 步：服务器安装（登录服务器后整段粘贴）

```bash
ssh root@49.234.179.153
```

```bash
mkdir -p /opt/yonghong/src && \
tar -xzf /root/yonghong-platform-src-2026.08.12.tar.gz -C /opt/yonghong/src --strip-components=1 && \
cd /opt/yonghong/src && \
bash deploy/install-tencentos.sh
```

跑完会打印访问地址、管理员账号、随机初始密码、入口口令。**抄下来。**

## 第 3 步：放行端口

腾讯云控制台 → 云服务器 → 安全组 → 入站规则 → 添加 `TCP:8911`。
**来源填你办公室的出口 IP**，别填 `0.0.0.0/0` —— 现在是明文 HTTP。

然后浏览器打开：

```
http://49.234.179.153:8911
```

---

## 进去先做什么

1. **登录** → 用打印出来的账号密码，系统会要求改密。
2. **灌一份数据**：左上角"勇虹"品牌区 **4 秒内连击 3 次** → 输入口令 `yonghong`
   → 「审核与发布」→ **一键载入示范数据并正式发布** → 二次确认。
   20 台设备的完整数据，走的是和真实数据一模一样的发布链路。
3. **回平台看**：驾驶舱、全面监测（五大类 30 项指标）、单机档案、运营改进中心、
   导出报告、大屏投屏，左侧菜单挨个点。
4. **试真实数据**：数据准备中心 →「文件导入」→ 下载模板 → 填数 → 导入 → 字段映射
   → 质量门禁 → 复核 → 发布。**金额一律填万元**。

## 试坏了想重来

```bash
bash /opt/yonghong/src/deploy/reset-data.sh
```

清空数据回到刚装好的状态，账号密码不变，可以反复试。
（示范数据同一医院只允许一个已发布版本，想再发一次必须先清库。）

## 常用命令

```bash
systemctl restart yonghong-platform          # 重启
systemctl status  yonghong-platform          # 状态
journalctl -u yonghong-platform -f           # 实时日志
curl http://127.0.0.1:8911/healthz           # 服务器上自检，返回 {"ok":true}
```

## 升级到新版本

```bash
scp 新包.tar.gz root@49.234.179.153:/root/          # 本地
rm -rf /opt/yonghong/src && mkdir -p /opt/yonghong/src && \
tar -xzf /root/新包.tar.gz -C /opt/yonghong/src --strip-components=1 && \
cd /opt/yonghong/src && bash deploy/install-tencentos.sh
```

数据和配置都保留，只换程序。

## 彻底卸载

```bash
systemctl disable --now yonghong-platform
rm -f /etc/systemd/system/yonghong-platform.service && systemctl daemon-reload
rm -rf /opt/yonghong
userdel yonghong
```

## 排查

| 现象 | 处理 |
|---|---|
| 浏览器打不开 | 先在服务器上 `curl http://127.0.0.1:8911/healthz`。能通 → 安全组没放行 8911；不通 → `journalctl -u yonghong-platform -n 50` |
| 装到一半说 Node 装不上 | 服务器没外网。去 `https://registry.npmmirror.com/-/binary/node/` 下 v22 的 linux-x64 包，解压后 `ln -s .../bin/node /usr/bin/node`，重跑脚本 |
| 一键发布点了没反应 | 多半是已经发布过了（同院只允许一个版本），先跑 `reset-data.sh` |
| 报表日期差一天 | `timedatectl set-timezone Asia/Shanghai` 后重启服务 |

## 正式给医院用的时候

现在是**试用模式**：明文 HTTP，会话 Cookie 已降级。正式上线要做三件事，
详见 [`部署手册-腾讯云-中国区.md`](./部署手册-腾讯云-中国区.md)：

1. 备案域名 + 装腾讯云免费证书；
2. `bash deploy/install-tencentos.sh --behind-nginx` 收回到只听本机，由 nginx 提供 HTTPS；
3. 安全组关掉 8911 只留 443；把入口口令 `yonghong` 改掉。
