# 单机试用 · 快速开始

一台腾讯云服务器，不用域名、不用证书、不用 Docker。三步跑起来。

## 1. 上传解压

```bash
scp yonghong-platform-src-*.tar.gz root@<服务器IP>:/root/
ssh root@<服务器IP>
tar -xzf yonghong-platform-src-*.tar.gz && cd yonghong-platform-src-*
```

## 2. 安装

```bash
bash deploy/install-tencentos.sh
```

跑完会打印三样东西，抄下来：

```
浏览器打开：  http://<你的服务器IP>:3000
管理员账号：  yh.admin
初始密码：    xxxxxxxxxxxx      ← 随机生成，首次登录会要求改密
入口口令：    yonghong          ← 进数据准备中心用
```

## 3. 放行端口

腾讯云控制台 → 云服务器 → 安全组 → 入站规则 → 添加 `TCP:3000`。
**来源填你办公室的出口 IP**，不要填 `0.0.0.0/0`——现在是明文 HTTP，别对全网开着。

打开 `http://<服务器IP>:3000` 就能用了。

---

## 进去先看什么

1. **登录** → 用打印出来的账号密码，系统会让你改密码。
2. **灌一份数据**：左上角品牌区（"勇虹"那块）**4 秒内连击 3 次** → 输入入口口令 `yonghong`
   → 进「审核与发布」→ 点 **一键载入示范数据并正式发布** → 二次确认。
   这会生成 20 台设备的完整脱敏数据，走的是和真实数据一模一样的发布链路。
3. **回平台看**：驾驶舱、全面监测（五大类 30 项指标）、单机档案、运营改进中心、
   导出报告、大屏投屏模式，左侧菜单挨个点。
4. **想试真实数据**：数据准备中心 →「文件导入」→ 下载模板 → 填数 → 导入 → 字段映射
   → 质量门禁 → 复核 → 发布。**金额一律填万元**。

## 试坏了想重来

```bash
bash deploy/reset-data.sh
```

清空全部数据回到刚装好的状态，管理员账号密码不变，可以反复试。

## 常用命令

```bash
systemctl restart yonghong-platform     # 重启
journalctl -u yonghong-platform -f      # 看日志
systemctl status yonghong-platform      # 看状态
```

数据都在 `/var/lib/yonghong-platform`，要备份就整个目录拷走。

## 排查

| 现象 | 处理 |
|---|---|
| 浏览器打不开 | 十有八九是安全组没放行 3000；`curl http://127.0.0.1:3000/healthz` 在服务器上能通就说明服务是好的 |
| 装到一半说 Node 装不上 | 服务器没外网。去 `https://registry.npmmirror.com/-/binary/node/` 下 v22 的 linux-x64 包，解压后 `ln -s .../bin/node /usr/bin/node`，再重跑脚本 |
| 一键发布点了没反应 | 看是不是已经发布过了（同一医院只允许一个已发布版本）；`bash deploy/reset-data.sh` 后重试 |
| 报表日期差一天 | 服务器时区不对，`timedatectl set-timezone Asia/Shanghai` 后重启服务 |

## 后面要给医院正式用的时候

现在是**试用模式**：明文 HTTP，会话 Cookie 已降级。正式上线前要做三件事，
详见 [`部署手册-腾讯云-中国区.md`](./部署手册-腾讯云-中国区.md)：

1. 备案域名 + 装腾讯云免费证书；
2. `bash deploy/install-tencentos.sh --behind-nginx` 改为只听本机，由 nginx 提供 HTTPS；
3. 安全组关掉 3000，只留 443；把入口口令 `yonghong` 改掉。
