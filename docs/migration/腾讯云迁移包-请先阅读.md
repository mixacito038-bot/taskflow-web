## 重要：当前不能直接作为腾讯云生产服务启动

当前服务端目标仍是 Cloudflare Worker，并使用 D1/SQLite、R2 和 Sites 身份入口。参考构建中的 `dist/client` 没有独立 `index.html`，`dist/server` 只导出 Worker `fetch`，都不能直接作为 CVM/PM2/容器服务启动。部署腾讯云前必须完成以下适配：

1. 把 Worker 入口改为标准 Node.js 服务/容器入口；
2. 把 Drizzle D1/SQLite schema 与 0000—0010 SQL 转换为 TencentDB MySQL；
3. 把 R2 对象存储调用适配为私有 COS；
4. 把 Sites/ChatGPT 身份入口替换为医院认可的 OIDC、企业微信或自有账号体系；
5. 配置 HTTPS、CAM 最小权限、备份恢复、日志告警和健康检查；
6. 使用脱敏数据完成一次全链路迁移演练后再开放正式访问。

当前源码没有标准 Node HTTP 入口、Dockerfile、MySQL 迁移、COS 适配器或 OIDC 实现；`tencent-cloud/nginx.conf.example` 也只是目标配置示例，暂时没有可承接 `127.0.0.1:3000` 的腾讯云 Node 进程。

当前业务数据入口只包含 Excel、CSV、JSON 文件，不包含 HIS、PACS 在线接口执行器。
